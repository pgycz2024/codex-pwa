CODEX REMOTE GUIDE

使用帮助

手机远程控制 Linux 上的 Codex

手机和服务器先加入同一个蒲公英或其他受控私网，再用浏览器打开本页面。Windows 电脑关机后，只要服务器和 Codex daemon 仍在运行，任务也会继续。

开始使用

从“新建任务”选择工作目录，设置模型、推理强度和访问权限，然后发送第一条消息。已有任务可直接点开继续。

运行中与跨端交接

绿色状态表示任务仍在运行。手机和 Windows 可以查看同一任务；“停止实时跟进”只停止当前网页订阅，不会终止服务器任务。

审批与权限

“请求批准”需要你逐项处理；“帮我批准”由 Codex 自动审阅；“完全批准”权限最大，请只在可信目录和可信任务中使用。

文件与附件

附件会保存到任务工作目录。侧栏“服务器文件”可以浏览、预览和下载授权根目录内的文件。

Goal 模式

Goal 是跨多轮保留的长期目标；执行计划则是单轮活动。目标支持暂停、继续和清除，清除目标不会删除整个会话。

连接故障

若页面停滞，先确认蒲公英已连接，再刷新页面。切换手机 App 后回到浏览器，页面会自动恢复任务状态和实时输出。

Web UI 使用帮助对话默认只做解释和诊断；不会自动修改 PWA。若要提出改进，会先要求 Codex 给出方案和影响范围。
