# 无障碍交互核对

本次核对使用真实 Chrome 的 Accessibility Tree 和 DevTools 键盘输入，配合隔离 PWA、模拟任务数据与既有移动端回归。没有连接或修改生产任务，也没有把浏览器语义树检查描述为真实读屏软件的语音验收。

## 已发现并修复

| 流程 | 原问题 | 当前行为与验证 |
| --- | --- | --- |
| 手机任务侧栏 | 关闭后仅 CSS 移出屏幕，读屏仍能访问，键盘也能进入 | 关闭时 `inert` 并从语义树隐藏；打开后有具名 dialog 与模态状态，背景不可聚焦；Tab 留在抽屉，Esc 返回触发按钮 |
| 任务详情 | 折叠面板没有统一焦点/展开状态，移动和桌面语义相同 | 手机按模态面板处理，桌面保留非模态 landmark；测试断点切换、背景输入可达性、Tab 分类和焦点返回 |
| 弹窗关闭 | 原触发按钮随侧栏隐藏后，焦点仍返回屏幕外 | 原按钮不可用时返回可见入口；按实际打开顺序识别最上层弹窗，嵌套 Esc 只关闭当前层 |
| 操作菜单 | 声明 menu，但缺少菜单键盘行为；原生弹窗内菜单挂在 body，可能位于模态层外 | 菜单放在所属面板/弹窗内，支持时用原生 popover 顶层避免遮挡；支持方向键、Home/End、Esc 和 Tab，关闭返回触发按钮 |
| 任务打开 | 侧栏关闭等待图片请求，期间状态刷新可能让关闭动作失效 | 任务正文和路由确认后立即关闭侧栏，辅助资源继续加载 |
| 表单名称 | 工作目录没有关联标签；搜索和消息输入依赖 placeholder；问答自由输入只叫“输入回答” | 增加稳定名称与说明关系，问答选项有分组名称，自由输入关联具体问题 |
| 并发审批/问答 | 新审批到达会重建所有卡片，清空正在填写的答案和选择范围 | 复用内容未变化的卡片；新增或移除其他审批均保留原答案、焦点及光标选择范围 |
| 任务列表更新 | 背景刷新重建卡片，勾选框失焦；新增任务推动当前阅读位置 | 按任务 ID 复用卡片与项目分组，保留聚焦控件和可见卡片偏移；显式同步不先清空列表；任务消失后返回相邻同类控件 |
| 相同消息同步 | 重绘 Markdown 和移动轮次容器，使目录折叠、链接失焦、文字选择消失 | 正文和流式状态未变时保留原正文，不无谓移动轮次；Chrome 核对链接节点/焦点、展开目录及原文本选择仍在 |
| 历史节点虚拟列表 | 滚动范围变化会替换仍在屏幕上的按钮，键盘无法连续跨范围翻阅 | 复用节点按钮并提供列表序号；方向键、Home/End 和 PageUp/PageDown 跨范围移动，出屏幕焦点仅额外保留一行；搜索继续持有焦点 |
| 完整历史正文窗口 | 换页时清空所有节点，重叠轮次也失去展开状态；上下文请求开始即跳回原节点 | 复用重叠轮次，保存被移出窗口内容的轻量展开状态；最多显示 160 个轮次，分页后给出可聚焦的阅读入口；上下文追加保持原焦点和阅读行位置 |
| 活动记录同步 | 命令被重新折叠，工具/文件卡片和失败轮次操作被重建 | 相同快照复用卡片、输出控件、已加载 Diff 和重试按钮；正式完整记录只移除已消失的条目；相同输出不替换原文本节点 |
| 弹窗菜单与后台更新 | 后台对话发生滚动，会关闭文件弹窗中的菜单 | 只在菜单入口的滚动祖先移动时关闭，背景对话滚动不影响文件菜单；入口所在列表滚动仍关闭菜单 |
| 状态朗读 | 整个对话和任务列表属于 live region，流式/历史更新可能反复朗读；页面外 toast 在原生弹窗期间不可感知 | 对话保留具名 log，关闭整段自动朗读；连接、任务结果、待审批和操作反馈使用简短状态区域，位于当前最上层弹窗/抽屉内 |
| 主题对比度 | 深色危险确认白字/浅红底为 2.77:1，部分辅助文字不足 4.5:1 | 危险操作使用独立深红按钮底色，保留错误文本色；校正深浅色辅助文字，主题令牌矩阵达到普通文字 4.5:1 |
| 手机触摸区域 | 多个按钮和筛选只有 30–40 像素，复选框只有 18–20 像素命中区域 | 主要交互控件至少 44 CSS 像素，复选框由关联标签扩大区域；Chrome 触摸事件在图形外的标签边缘也能选择任务/文件夹 |
| 文件夹复选框 | 标签边缘或空格键可能冒泡到目录打开行为 | 标签点击和复选框空格键仅改变选择，行本身收到键盘激活时才进入目录 |
| 文字放大与短屏幕 | 固定像素字号不随浏览器基准字号变化；固定历史行高不能容纳放大文字 | 界面采用相对字号，正文、表单和按钮随基准字号缩放；短视口面板可滚动，历史行高重新测量并保留原焦点 |

## 验证范围

- 17 个原生弹窗：实际语义树中的 dialog 角色、标题和可见表单控件/按钮名称；模态背景不可读，Esc 正常关闭。
- 手机侧栏、任务详情、桌面断点、嵌套弹窗与菜单键盘流程；文件菜单的实际可点击位置，避免只检测 DOM 存在。
- 当前弹窗中的状态反馈可在语义树中访问，嵌套弹窗按打开顺序接收公告；大段流式正文不会作为全局 live region 重复推送。
- 收到其他审批、移除之前的审批时保留问答内容和焦点；已有的写入队列取消/回复丢失、消息时间、历史定位、通知等移动回归继续执行。
- 80 条任务的刷新、插入、勾选和删除：保留同一复选框与勾选状态，阅读卡片位置变化小于 3 像素；消息重新同步保留同一链接和选中文本。
- 800 个历史节点：跨虚拟范围连续按方向键、跳到首尾、整页翻阅，及指针滚动后的屏幕外焦点保留；始终少于 80 个按钮，搜索缩减到一个节点不抢焦点。列表项在 Chrome 语义树中具有 `listitem` 角色，DOM 提供 `aria-posinset`/`aria-setsize`，未全部加载时总数为未知。
- 160 轮正文窗口前后翻页，重叠轮次保持同一 DOM，移出窗口的内容被释放；返回后恢复折叠组和长回复展开。上下文由 20 轮追加为 40 轮，原按钮/焦点/展开保留，阅读行偏移小于 3 像素。
- 相同快照与完整活动替换保留已展开的 16,000 字符命令输出、工具卡片、480 行已加载 Diff 和失败重试按钮。阅读位置补偿使用立即滚动；历史定位反馈停留在固定的上下文提示下方。
- 深浅两套主题分别核对 32 组文字/背景令牌对比度，共 64 组；这是维护用的主题颜色约束，不等同于所有图片、透明叠层、禁用状态或动态组件的逐像素审计。
- 触摸区域：侧栏、顶部按钮、详情面板、输入区、17 个原生弹窗、文件选择及动态审批/问答的可见主要控件，按控件或关联标签矩形核对至少 44×44 CSS 像素；正文内行内链接未机械扩大。额外通过 Chrome 触摸输入核对任务和文件夹复选框标签边缘，文件夹空格键不会发起目录读取。
- 200% 浏览器基准字号：将根字号设为 32px，在 320×480 CSS 像素视口中核对 17 个弹窗横向不溢出、按钮文字不被纵向裁切、底部操作可滚动到达。历史列表仍少于 80 个按钮，日期在行内、字体变化保留焦点，恢复基准字号后虚拟高度恢复。

## 独立账号的字体差异补充（v113）

完整候选包通过维护账号检查后，独立新 Linux 账号的实际更新检查发现：200% 根字号下，17 个弹窗关闭按钮均超出固定 44px 高度 2px。修复将图标按钮改为最小高度与内容自适应，默认触摸区域仍保持手机至少 44px、桌面至少 40px；不依赖特定字体的 `normal` 行高。移动 Chrome 回归在 200% 字号下为图标按钮设置 1.5 行高，旧样式稳定复现 4px 溢出，避免维护者已安装字体掩盖缺陷。

修复后维护账号的候选打包检查，以及独立新账号的实际升级/故障回滚候选检查均为 268/268，Chrome 未跳过；17 个弹窗的放大文字、触摸与焦点检查通过。完整包的实际更新证据见 `RELEASE_ACCEPTANCE.md`。

## 受限字体的标签触摸区域（v118）

Chrome 153 仅加载 DejaVu/Liberation、未加载 CJK 字体时，目录隐藏开关、授权范围搜索开关和文件隐藏开关的关联标签只有 40.84375px 宽，44px 高。移动端样式此前只限制这些标签的最小高度。现为关联标签同时设置 44px 最小宽度，使命中区域不再依赖文字宽度；复选框图形保持原尺寸。

使用相同的隔离字体配置运行完整 `test/mobile-browser.test.mjs`，修改前在三个标签尺寸断言处失败，修改后全部通过，包括触摸尺寸、17 个弹窗、200% 浏览器字号和菜单/任务恢复等既有回归。这是受限字体环境的浏览器证据，不替代以下实机验收。

## 仍需核对

真实手机的 VoiceOver/TalkBack 朗读、触摸探索、系统字号设置和软键盘，以及 Windows 读屏体验仍需实际设备验证。根字号/视口和 Chrome 触摸注入不等同于各手机系统的文字缩放、真实手指或软键盘验收；动态内容与第三方预览也未逐一覆盖。以上窗口/活动回归使用受控数据，不等同于真实多端长任务验收。离开窗口释放正文后，文本选择、Diff 已加载页数和单独请求的远程大输出不随轻量展开状态缓存；返回时需要重新展开/加载这些重内容。复杂叠层对比度继续保留；统一文案管理的完成范围见 `UI_COPY.md`。
